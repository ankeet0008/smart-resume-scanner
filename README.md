# Smart Resume Scanner

## Overview
Smart Resume Scanner is a web-based application that automates resume analysis using NLP. It extracts skills from PDF resumes, evaluates resume content, and provides recommendations to improve employability.

## Features
- Upload resumes in PDF format
- Automatic text extraction from resumes
- Skill identification using NLP
- Resume scoring and recommendations

## Technologies Used
- React + TypeScript (frontend)
- Python (parsing utilities)
- spaCy
- NLTK
- PyPDF2
- MySQL (optional)

## How to Run
### Frontend
1. Install dependencies:
   ```bash
   cd frontend
   npm install
   ```
2. Start the dev server:
   ```bash
   npm run dev
   ```

### TypeScript backend library
1. Build the library:
   ```bash
   cd backend
   npm install
   npm run build
   ```
