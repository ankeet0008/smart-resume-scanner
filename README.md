# Smart Resume Scanner

## Overview
Smart Resume Scanner is a web-based application that automates resume analysis using Natural Language Processing (NLP). It extracts skills from PDF resumes, evaluates resume content, and provides recommendations to improve employability.

## Features
- Upload resumes in PDF format
- Automatic text extraction from resumes
- Skill identification using NLP
- Resume scoring and recommendations
- Admin panel for monitoring (optional)

## Technologies Used
- Python
- Streamlit
- spaCy
- NLTK
- PyPDF2
- MySQL (optional)
